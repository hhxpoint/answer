## 中药识别功能 - 小程序端对接文档

服务端已部署完成，API 已上线。本文档描述小程序端需要做的改动。

---

### 1. API 信息

**端点**: `POST https://hhxgo.tech/api/detect/herbs`

**请求格式** (与数字识别/物体检测完全一致):
```json
{
  "image": "data:image/jpeg;base64,/9j/4AAQ..."
}
```

**成功响应**:
```json
{
  "detections": [
    {
      "x1": 120,
      "y1": 80,
      "x2": 340,
      "y2": 290,
      "score": 0.9234,
      "classId": 9,
      "className": "甘草"
    },
    {
      "x1": 400,
      "y1": 150,
      "x2": 580,
      "y2": 380,
      "score": 0.8521,
      "classId": 3,
      "className": "牡丹皮"
    }
  ],
  "inference_time_ms": 156
}
```

**响应字段说明**:
- `detections` — 检测到的中药列表，可能为空数组
- `detections[].x1,y1,x2,y2` — 检测框像素坐标（左上角 + 右下角）
- `detections[].score` — 置信度 0~1
- `detections[].classId` — 类别ID (0-14)
- `detections[].className` — 中文药名（直接展示即可）
- `inference_time_ms` — 推理耗时毫秒

**15类中药**: 泽泻(0), 牛膝(1), 高良姜(2), 牡丹皮(3), 玉竹(4), 白芷(5), 白芍(6), 大枣(7), 丹参(8), 甘草(9), 白鲜皮(10), 百合(11), 桑枝(12), 桔梗(13), 板蓝根(14)

**错误响应**:
- `{"error": "图片大小超过限制"}` — 413
- `{"error": "中药识别模型未加载"}` — 503
- `{"error": "中药识别失败: ..."}` — 500

### 2. 小程序端改动

#### 2.1 detect-api.js — 加一个函数

```javascript
function recognizeHerbs(imagePath) {
  return _imageToBase64(imagePath).then(function(base64) {
    return new Promise(function(resolve, reject) {
      wx.request({
        url: API_URL + '/api/detect/herbs',
        method: 'POST',
        header: _getAuthHeader(),
        data: JSON.stringify({ image: base64 }),
        timeout: 8000,
        success: function(res) {
          if (res.statusCode >= 200 && res.statusCode < 300 && res.data) {
            resolve(res.data);
          } else {
            reject(new Error('服务返回错误: ' + res.statusCode));
          }
        },
        fail: function(err) {
          reject(new Error('网络请求失败: ' + (err.errMsg || '')));
        }
      });
    });
  });
}
```

在 `module.exports` 中加入:
```javascript
module.exports = {
  recognizeDigit: recognizeDigit,
  detectObjects: detectObjects,
  recognizeHerbs: recognizeHerbs  // 新增
};
```

#### 2.3 detect.js — 加 herb 模式逻辑

在 `data` 中加:
```javascript
herbResults: null,
herbInferenceTime: 0
```

加拍照和选图方法 (复制 digit 的改 API 调用):
```javascript
captureHerb: function() {
  var self = this;
  self._cameraCtx.takePhoto({
    quality: 'high',
    success: function(photo) {
      self._processHerbImage(photo.tempImagePath);
    },
    fail: function() {
      wx.showToast({ title: '拍照失败', icon: 'none' });
    }
  });
},

chooseHerbImage: function() {
  var self = this;
  wx.chooseMedia({
    count: 1,
    mediaType: ['image'],
    sourceType: ['album'],
    success: function(res) {
      self._processHerbImage(res.tempFiles[0].tempFilePath);
    }
  });
},

_processHerbImage: function(imagePath) {
  var self = this;
  self.setData({ herbResults: null });
  self._showLoadingCanvas('识别中...');

  var img = self._canvasNode.createImage();
  img.onload = function() {
    var canvas = self._canvasNode;
    var ctx = self._canvasCtx;
    canvas.width = img.width;
    canvas.height = img.height;
    self._canvasW = img.width;
    self._canvasH = img.height;
    ctx.setTransform(1, 0, 0, 1, 0, 0);

    var t0 = Date.now();
    detectApi.recognizeHerbs(imagePath).then(function(result) {
      var dt = Date.now() - t0;
      self._clearCanvas();

      var detections = result.detections || [];
      // 复用 YOLO 绘制函数（已支持自定义 className + score）
      canvasRender.drawYoloDetections(ctx, detections, self._canvasW, self._canvasH);

      var herbList = detections.map(function(d) {
        return {
          className: d.className,
          classId: d.classId,
          score: d.score,
          scorePercent: Math.round(d.score * 100)
        };
      });

      self.setData({
        herbResults: herbList,
        herbInferenceTime: result.inference_time_ms || dt
      });
    }).catch(function(err) {
      console.error('[Detect] 中药识别失败:', err);
      self._clearCanvas();
      wx.showToast({ title: '识别失败，请重试', icon: 'none' });
      self.setData({ herbResults: [], herbInferenceTime: 0 });
    });
  };

  img.onerror = function() {
    self._clearCanvas();
  };

  img.src = imagePath;
}
```
