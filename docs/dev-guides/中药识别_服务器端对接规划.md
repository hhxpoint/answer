## 二、新增 `/api/detect/herb` 端点方案

### 2.1 路由注册（零 nginx 改动）

**关键点**：新端点 `/api/detect/herb` 在已有的 `/api/detect/` 路由组下，nginx 已有的反向代理规则：

```nginx
# 假设当前 nginx 配置（无需修改）
location /api/detect/ {
    proxy_pass http://127.0.0.1:<port>/api/detect/;
}
```

已经覆盖 `/api/detect/herb` 路径，**无需任何 nginx 配置变更**。

只需在应用代码中新增一个路由处理器即可。

### 2.2 推理模型选型

#### 方案 A：基于图像分类模型（推荐）

```
输入：中药饮片照片 (224x224 或 384x384)
模型：ResNet50 / EfficientNet-B0 / ConvNeXt-Tiny
输出：N类中药的概率分布
后处理：Top-K + 置信度过滤
```

**优势**：
- 模型小（ResNet50 约 100MB，EfficientNet-B0 约 20MB）
- 推理快（CPU 30-80ms，GPU 5-15ms）
- 标注成本低（只需图片级标签，不需要 bbox 标注）
- 准确率高（中药饮片形态差异明显，分类任务天然适合）

**适用场景**：用户拍的是**单一药材**的照片

#### 方案 B：基于目标检测模型

```
输入：任意照片 (640x640)
模型：YOLOv8-m / RT-DETR
输出：bbox + 类别 + 置信度
后处理：NMS + 置信度过滤
```

**优势**：
- 支持一张照片中识别**多种药材**
- 可定位药材在图片中的位置

**劣势**：
- 需要 bbox 标注数据，标注成本高
- 模型更大，推理更慢
- 中药场景通常是一次拍一种药材，检测模型过度设计

#### 推荐：方案 A（分类模型）

理由：中药识别的使用场景是"用户对着一种药材拍照 → 识别是什么"，分类模型完全够用，且开发成本最低。

**herb_detect.py 实现框架**：

```python
import onnxruntime as ort
import numpy as np
from PIL import Image
import io
import base64
import json
import time

# 加载模型（启动时加载一次）
session = ort.InferenceSession("models/herb_classifier.onnx")
input_name = session.get_inputs()[0].name

# 加载知识库
with open("data/herb_knowledge.json", "r", encoding="utf-8") as f:
    HERB_DB = json.load(f)

# 类别列表（与训练时一致）
HERB_CLASSES = ["黄芪", "当归", "枸杞子", ...]  # 50个类别

def decode_base64_image(data_uri: str) -> Image.Image:
    """解码 Data URI 格式的 Base64 图片"""
    # 复用已有的 image_decode 工具，或如下实现
    header, data = data_uri.split(",", 1)
    img_bytes = base64.b64decode(data)
    return Image.open(io.BytesIO(img_bytes))

def preprocess(img: Image.Image) -> np.ndarray:
    """图片预处理：Resize + Normalize"""
    img = img.resize((224, 224))
    arr = np.array(img).astype(np.float32) / 255.0
    mean = np.array([0.485, 0.456, 0.406])
    std = np.array([0.229, 0.224, 0.225])
    arr = (arr - mean) / std
    arr = arr.transpose(2, 0, 1)  # HWC -> CHW
    return arr[np.newaxis, ...]   # 添加 batch 维度

def handle_herb_detect(request_body: dict) -> dict:
    """处理中药识别请求"""
    t0 = time.time()

    # 1. 解码图片
    image_data = request_body.get("image", "")
    if not image_data:
        return {"error": "image is required"}, 400

    try:
        img = decode_base64_image(image_data)
    except Exception:
        return {"error": "invalid image format"}, 400

    # 2. 预处理
    input_tensor = preprocess(img)

    # 3. 推理
    outputs = session.run(None, {input_name: input_tensor})
    probs = softmax(outputs[0][0])  # 应用 softmax 获取概率

    # 4. Top-K 结果
    top_k = 3
    top_indices = np.argsort(probs)[::-1][:top_k]

    primary_idx = top_indices[0]
    primary_conf = float(probs[primary_idx])
    primary_name = HERB_CLASSES[primary_idx]

    # 5. 构造响应
    herb_info = HERB_DB.get(primary_name, {})
    alternatives = []
    for idx in top_indices[1:]:
        if probs[idx] > 0.05:  # 置信度 > 5% 才返回
            alternatives.append({
                "name": HERB_CLASSES[idx],
                "confidence": round(float(probs[idx]), 2)
            })

    dt = int((time.time() - t0) * 1000)

    if primary_conf < 0.3:  # 置信度太低，认为未识别到
        return {
            "herb": {"name": "", "confidence": 0},
            "alternatives": [],
            "inference_time_ms": dt
        }

    return {
        "herb": {
            "name": primary_name,
            "latin_name": herb_info.get("latin_name", ""),
            "confidence": round(primary_conf, 2),
            "category": herb_info.get("category", ""),
            "properties": {
                "性味": herb_info.get("性味", ""),
                "归经": herb_info.get("归经", ""),
                "功效": herb_info.get("功效", ""),
                "主治": herb_info.get("主治", "")
            }
        },
        "alternatives": alternatives,
        "inference_time_ms": dt
    }

def softmax(x):
    e = np.exp(x - np.max(x))
    return e / e.sum()
```
