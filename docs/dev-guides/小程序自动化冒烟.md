# 小程序自动化冒烟（开发者工具模拟器）

> 目的：发版前用脚本把关键页面跑一遍，做「渲染 + 路由 + 数据」三层断言，替代人工点。
> 脚本：`tools/automator/smoke.js`、`tools/automator/run-smoke.ps1`
> 完整步骤与排障：[tools/automator/README.md](../../tools/automator/README.md)

---

## 一条命令

```powershell
cd tools\wx-auto            # 或任意目录，脚本内部用绝对路径
powershell -NoProfile -ExecutionPolicy Bypass -File tools\automator\run-smoke.ps1 -Port 9492
```

输出：

```text
PASS index           200566B pages/index/index
...
SKIP couple-home     -B   ✗ exec:timeout
=== summary ===
pages 12 · PASS 9 · SKIP 3 · FAIL 0
SMOKE_OK
```

## 为什么需要它

静态检查（`tools/check_pages.py`）保证「接线没错」，页面测试保证「逻辑没错」，
但**页面到底渲染出来没有、数据加载成功没有**，只有真跑一遍才知道。
1.41.2 之前出过 `miniprogram_npm` 缺失导致翻译页白屏的问题——这类问题静态检查发现不了。

## 三层断言

| 层 | 判据 | 能抓住什么 |
|---|---|---|
| render | 截图 ≥ 15KB | 白屏 / 未渲染 / 页面崩溃 |
| route | `getCurrentPages()` 末位 = 期望 | reLaunch 无效、跳转被吞 |
| data | 页面 `data` 语义断言 | 数据没加载、字段缺失、接口失败静默 |

## 必须知道的四件事

1. **一次性准备**：`npm install` → `mkdir miniprogram_npm` → `cli.bat build-npm`。
   少这一步，IDE 编译失败、模拟器不启动，表现为「所有命令超时」——不是工具坏了。
2. **实例会退化**：automator 实例跑久了 `reLaunch` 不跳转、`getCurrentPages()` 停在旧页，
   所以 `run-smoke.ps1` 每次都重启实例，不要复用。
3. **SKIP 不等于通过**：`couple-*`、`trade-share` 依赖线上接口，本机网络不通会挂起，计 SKIP。
4. **模拟器 ≠ 真机**：相机、分享面板、字体、性能都测不了，真机仍要人验一次。

## 已踩过的坑（细节见 tools/automator/README.md）

- `page.$` / `page.waitFor` 在 automator 0.13.0 + 当前工具版本会挂起 → 改用截图 + `mp.evaluate`。
- `mp.currentPage()` 返回陈旧页面 → 用 `getCurrentPages()`。
- `automator.launch()` 只接受可执行文件，且会因 `.cli` 端口文件被占用报 `EPERM` → 用 `cli auto` + `connect`。
- `.ps1` 必须是 UTF-8 with BOM，否则 Windows PowerShell 5.1 会按 ANSI 解析中文注释而报错。
