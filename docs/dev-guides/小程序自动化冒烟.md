# 小程序自动化冒烟（开发者工具模拟器）

> 目的：每次发版前用脚本把关键页面跑一遍，替代人工点。工具：`miniprogram-automator`。
> 脚本：`tools/automator/smoke.js` · 详细步骤与排障：`tools/automator/README.md`

---

## 为什么需要它

静态检查（`tools/check_pages.py`）能保证「接线没错」，页面测试能保证「逻辑没错」，
但**页面到底渲染出来没有**，只有真跑一遍才知道。1.41.2 之前就出过
`miniprogram_npm` 缺失导致翻译页、文章页白屏的问题——这类问题静态检查发现不了。

## 一次性准备（漏了会以「RPC 全部超时」的假象出现）

```powershell
cd <项目根>
npm install
mkdir miniprogram_npm            # project.config.json 是 packNpmManually: true，目录要先存在
& 'D:\develop_tool\微信web开发者工具\cli.bat' build-npm --project <项目根>
```

## 每次执行

```powershell
& 'D:\develop_tool\微信web开发者工具\cli.bat' quit
Get-Process | Where-Object { $_.Path -like '*develop_tool*' } | Stop-Process -Force
& 'D:\develop_tool\微信web开发者工具\cli.bat' auto --project <项目根> --auto-port 9484 --trust-project
# 等 40~60 秒
node tools/automator/smoke.js 9484
```

## 判据

| 判定 | 说明 |
|---|---|
| 截图 ≥ 15KB | 页面有内容；白屏约 2.5KB |
| `getCurrentPages()` 末位路由 = 期望路径 | 防止 reLaunch 没生效却「跑过了」 |
| `optional: true` 的页面 | 依赖线上接口，本机网络不通会挂起，计为 SKIP |

## 当前覆盖（2026-11-25）

```text
index / trade-home / trade-market / trade-mylist / trade-publish
trade-estimate / trade-detail / trade-sources / recipe-home   → 9 页 PASS
couple-home / couple-spaces / trade-share                     → 3 页 SKIP（依赖线上接口）
```

## 已踩过的坑

1. `page.$` / `page.waitFor` 在 automator 0.13.0 + 当前开发者工具版本会**挂起**（不返回也不报错）
   → 改用「截图 + `mp.evaluate` 取路由」判定。
2. `mp.currentPage()` 返回**陈旧页面**，不能用来校验导航结果。
3. `automator.launch()` 需要可执行文件作为 `cliPath`（`.bat` 会被拒），
   且会因 `.cli` 端口文件被占用报 `EPERM` → 改用 `cli auto` + `connect`。
4. 上一轮挂起的运行会把模拟器留在白屏，**每次跑之前重启自动化实例**。
