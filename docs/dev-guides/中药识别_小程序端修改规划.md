# 中药识别 —— 小程序端修改规划

> 目标：在现有 `packageDetect` 模块中新增「中药识别」模式，复用已有的摄像头采集、Base64上传、Canvas绘制架构，**最小改动、零新增分包**。

---

## 一、现状分析

### 1.1 当前模式架构

`packageDetect/pages/detect/detect` 页面采用 **Tab 模式切换** 架构：

```
┌─────────────────────────────────┐
│  [数字识别]   [物体检测]          │  ← mode-tabs 切换
├─────────────────────────────────┤
│                                 │
│       摄像头 + Canvas覆盖层       │  ← camera-wrap
│                                 │
├─────────────────────────────────┤
│     控制栏 (拍照/选图/开始停止)    │  ← controls
├─────────────────────────────────┤
│     结果面板 / 统计栏             │  ← result-panel / stats-bar
└─────────────────────────────────┘
```

- `data.activeMode` 控制当前模式：`'digit'` 或 `'yolo'`
- `switchMode(e)` 处理 Tab 切换，`e.currentTarget.dataset.mode` 传入目标模式
- 不同模式对应不同的控制栏（wxml 中用 `wx:if="{{activeMode === 'xxx'}}"` 条件渲染）
- 不同模式对应不同的结果展示面板

### 1.2 API 请求模式

```
小程序端                              服务器 hhxgo.tech
─────────                           ──────────────
图片 → wx.readFile(base64)
     → JSON.stringify({image: base64})
     → wx.request(POST)
                                    → /api/detect/digit   (数字识别)
                                    → /api/detect/objects  (物体检测)
     ← JSON 响应                     ← { ...结果, inference_time_ms }
```

**关键特征**：
- 统一使用 `detect-api.js` 封装的函数
- 请求头自动携带 `Authorization: Bearer <token>`
- 超时 5000ms
- 响应格式：各端点自定义，但都包含 `inference_time_ms`

### 1.3 Canvas 渲染模式

`canvas-render.js` 提供独立的绘制函数，按模式调用：
- `drawDigitDetections()` — 数字检测框 + 标签
- `drawYoloDetections()` — YOLO 检测框 + 类别 + 置信度条
- `drawLoadingOverlay()` — 通用加载遮罩
- `drawDebugInfo()` — 通用调试信息

## 三、逐文件详细改动方案

### 3.1 `detect-api.js` — 新增 API 函数

**当前结构**（80行）：
```
L5:   var API_URL = 'https://hhxgo.tech';
L7-12: _getAuthHeader()      — 认证头
L14-27: _imageToBase64()     — 图片转 Base64
L29-51: recognizeDigit()     — POST /api/detect/digit
L53-75: detectObjects()      — POST /api/detect/objects
L77-80: module.exports       — 导出两个函数
```

**新增内容**（插入在 L75 之后，L77 之前）：

```javascript
function recognizeHerb(imagePath) {
  return _imageToBase64(imagePath).then(function(base64) {
    return new Promise(function(resolve, reject) {
      wx.request({
        url: API_URL + '/api/detect/herb',
        method: 'POST',
        header: _getAuthHeader(),
        data: JSON.stringify({ image: base64 }),
        timeout: 8000,  // 中药识别可能需要更长时间，给8秒
        success: function(res) {
          if (res.statusCode >= 200 && res.statusCode < 300 && res.data) {
            resolve(res.data);
          } else {
            reject(new Error('服务返回错误: ' + res.statusCode));
          }
        },
        fail: function(err) {
          reject(new Error('网络请求失败: ' + (err.errMsg || '')));
        }
      });
    });
  });
}
```

**修改 exports**：
```javascript
module.exports = {
  recognizeDigit: recognizeDigit,
  detectObjects: detectObjects,
  recognizeHerb: recognizeHerb    // 新增
};
```

**预期 API 响应格式**：
```json
{
  "herb": {
    "name": "黄芪",
    "latin_name": "Astragalus membranaceus",
    "confidence": 0.92,
    "category": "补气药",
    "properties": {
      "性味": "甘，微温",
      "归经": "脾、肺经",
      "功效": "补气升阳，固表止汗，利水消肿，生津养血",
      "主治": "气虚乏力，食少便溏，中气下陷，久泻脱肛"
    },
    "image_desc": "切片呈淡黄色，有豆腥气"
  },
  "alternatives": [
    { "name": "党参", "confidence": 0.15 },
    { "name": "白术", "confidence": 0.08 }
  ],
  "inference_time_ms": 320
}
```

> **设计说明**：`timeout` 设为 8000ms 而非 5000ms，因为中药识别模型可能比通用目标检测更重。`alternatives` 提供备选结果，增强用户体验。

#### 3.2.3 新增中药识别方法

在 `chooseImage()` 方法之后插入：

```javascript
// ================= 中药识别 =================

captureHerb: function() {
  var self = this;
  self._cameraCtx.takePhoto({
    quality: 'high',
    success: function(photo) {
      self._processHerbImage(photo.tempImagePath);
    },
    fail: function() {
      wx.showToast({ title: '拍照失败', icon: 'none' });
    }
  });
},

chooseHerbImage: function() {
  var self = this;
  wx.chooseMedia({
    count: 1,
    mediaType: ['image'],
    sourceType: ['album'],
    success: function(res) {
      self._processHerbImage(res.tempFiles[0].tempFilePath);
    }
  });
},

_processHerbImage: function(imagePath) {
  var self = this;
  self.setData({ herbResult: null });
  self._showLoadingCanvas('中药识别中...');

  var img = self._canvasNode.createImage();
  img.onload = function() {
    var canvas = self._canvasNode;
    var ctx = self._canvasCtx;
    canvas.width = img.width;
    canvas.height = img.height;
    self._canvasW = img.width;
    self._canvasH = img.height;
    ctx.setTransform(1, 0, 0, 1, 0, 0);

    var t0 = Date.now();
    detectApi.recognizeHerb(imagePath).then(function(result) {
      var dt = Date.now() - t0;
      self._clearCanvas();

      if (result.herb && result.herb.confidence > 0) {
        canvasRender.drawHerbResult(self._canvasCtx, result, self._canvasW, self._canvasH);

        self.setData({
          herbResult: {
            name: result.herb.name,
            confidence: Math.round(result.herb.confidence * 100),
            category: result.herb.category || '',
            properties: result.herb.properties || {},
            alternatives: result.alternatives || [],
            inferenceTime: result.inference_time_ms || dt
          }
        });
      } else {
        self.setData({
          herbResult: { name: '', inferenceTime: dt }
        });
      }
    }).catch(function(err) {
      console.error('[Detect] 中药识别失败:', err);
      self._clearCanvas();
      wx.showToast({ title: '识别失败，请重试', icon: 'none' });
      self.setData({ herbResult: { name: '', inferenceTime: 0 } });
    });
  };

  img.onerror = function() {
    console.error('[Detect] 图片加载失败:', imagePath);
    self._clearCanvas();
  };

  img.src = imagePath;
},
```

> **设计说明**：复用与 `_processDigitImage` 完全相同的图片加载 → Canvas 尺寸适配 → API 调用 → 结果渲染 流程。`captureHerb` / `chooseHerbImage` 的结构也与 `captureDigit` / `chooseImage` 完全对称。

### 3.5 `canvas-render.js` — 新增绘制函数

在 `drawDigitResultPanel` 之后、`roundRect` 之前插入：

```javascript
// 绘制中药识别结果（在图片上标注识别区域）
function drawHerbResult(ctx, result, canvasW, canvasH) {
  if (!result || !result.herb) return;

  var herb = result.herb;

  // 底部信息面板
  var panelH = 100;
  var panelY = canvasH - panelH - 10;
  var panelX = 10;
  var panelW = canvasW - 20;

  // 半透明背景
  ctx.fillStyle = 'rgba(0, 0, 0, 0.65)';
  roundRect(ctx, panelX, panelY, panelW, panelH, 12);
  ctx.fill();

  // 药名（大字）
  ctx.fillStyle = '#00ff88';
  ctx.font = 'bold 32px sans-serif';
  ctx.textAlign = 'left';
  ctx.fillText(herb.name, panelX + 16, panelY + 40);

  // 置信度
  var confText = Math.round(herb.confidence * 100) + '%';
  ctx.fillStyle = 'rgba(255, 255, 255, 0.5)';
  ctx.font = '16px sans-serif';
  ctx.textAlign = 'right';
  ctx.fillText(confText, panelX + panelW - 16, panelY + 40);

  // 分类标签
  if (herb.category) {
    ctx.textAlign = 'left';
    ctx.fillStyle = '#667eea';
    ctx.font = '14px sans-serif';
    ctx.fillText(herb.category, panelX + 16, panelY + 62);
  }

  // 功效摘要（取前20字）
  if (herb.properties && herb.properties['功效']) {
    ctx.fillStyle = 'rgba(255, 255, 255, 0.6)';
    ctx.font = '13px sans-serif';
    ctx.textAlign = 'left';
    var effect = herb.properties['功效'];
    if (effect.length > 20) effect = effect.substring(0, 20) + '...';
    ctx.fillText(effect, panelX + 16, panelY + 84);
  }

  ctx.textAlign = 'left';
}
```

## 五、Tab 三模式切换的 CSS 处理

当前 `.mode-tabs` 的 `gap: 16rpx` 在两个 Tab 时足够，三个 Tab 需要确认不溢出。

**屏幕宽度分析**：
- iPhone 6/7/8: 375px = 750rpx
- `padding: 16rpx 24rpx` → 可用宽度 = 750 - 48 = 702rpx
- 3个 Tab，每个 Tab 最小需要约 220rpx → 总计 660rpx + 32rpx gap = 692rpx ✅

**结论**：当前 CSS 布局（`flex: 1` + `gap: 16rpx`）天然支持三等分，无需额外调整。

但如果觉得 Tab 文字太挤，可以微调：

```css
/* 可选：三Tab模式下缩小字号 */
.mode-tabs .tab-text {
  font-size: 26rpx;  /* 从 28rpx 缩小 */
}
```

## 六、风险点与注意事项

| 风险 | 等级 | 应对 |
|------|------|------|
| API 响应格式与预期不符 | 中 | 在 `_processHerbImage` 中做好字段判空，`result.herb` 不存在时走空结果分支 |
| 中药模型推理耗时较长 | 低 | timeout 已设为 8000ms，且有 loading 遮罩提示 |
| Tab 三等分后文字显示不全 | 低 | 可选缩小字号，或使用 scroll-view |
| 服务器未部署 herb 端点 | 高 | 先部署服务器端，再发版小程序（见服务器端规划文档） |
