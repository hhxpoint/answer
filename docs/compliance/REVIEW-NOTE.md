# 审核说明 · 个人主体「社交-笔记」类目被拒

> 背景：2026-11-26 审核反馈「存在个人主体小程序未开放的服务类目……用户自行生成内容（文字、图片、音）的记录、分享，属社交-笔记范畴」。
> 本文档用于提交审核时填写备注，以及说明小程序的实际能力边界。

---

## 1. 小程序定位

「小火苗」是**两个人之间的私密互动工具**（生活服务类），不是社交产品：

- 用户通过对方发送的邀请码**一对一绑定**，每个关系空间**最多 2 人**
- 绑定后可在两人之间记录日常、留语音、记纪念日
- 所有内容**仅绑定双方可见**，不对外展示，不进入任何公开列表

---

## 2. 无社交能力（逐项）

| 常见社交能力 | 本小程序 |
|---|---|
| 公开发布 / 动态 / 广场 | 无 |
| 推荐 / 热门 / 话题 / 标签 | 无 |
| 关注 / 粉丝 / 个人主页展示 | 无 |
| 评论 / 点赞 / 打赏 | 无 |
| 陌生人搜索 / 附近的人 | 无 |
| 内容转发到好友或朋友圈 | **无**（分享能力仅用于「邀请对方绑定」与「打开小程序」，分享卡片不携带任何用户内容） |
| 通讯录 / 位置 / 相机权限 | 未申请通讯录、位置权限 |

小程序内**没有任何内容会展示给绑定关系之外的人**。

---

## 3. 内容管理

- 用户内容只在两人空间内可见；解除关系后该空间内容对双方不可再访问
- 如涉及违规内容，可通过「我的 - 反馈」联系开发者删除，承诺 24 小时内处理
- 未接入任何第三方内容平台

---

## 4. 页面说明

| 页面 | 性质 |
|---|---|
| 关系空间列表 | 用户自己的空间入口（仅自己可见） |
| 创建关系空间 | 需输入运营发放的创建口令 |
| 「两个人的空间」介绍页 | **静态介绍页**：预置文案与配图，说明这个产品是什么；无任何用户输入、评论、分享入口 |
| 空间内部（聊天 / 记录 / 纪念日 / 语音） | 仅两人可见 |

---

```
【功能说明】
本小程序为两人之间的私密互动工具（生活服务类）。用户需通过对方发送的邀请码
一对一绑定，每个关系空间最多 2 人。绑定后可在两人之间记录日常、留语音、记纪念日。
所有内容仅绑定双方可见，不对外展示。

【不存在社交能力】
小程序内不提供公开发布、广场、推荐、关注、粉丝、评论、点赞、话题、社区、
陌生人搜索、内容转发等任何社交功能；未接入任何内容推荐或陌生人发现机制。
分享能力仅用于「邀请对方绑定」与「打开小程序」，分享卡片不携带任何用户内容。
未申请通讯录、位置权限。

【内容管理】
用户内容仅在双方之间可见；解除关系后该空间内容对双方不可再访问。
如涉及违规内容，可通过「我的-反馈」联系开发者删除，我们承诺 24 小时内处理。

【类目说明】
主体为个人，功能定位为私密工具而非社交平台，恳请按「工具-生活服务」类目审核。
```

---

## 7. 如果仍被拒

按可能性排序：

1. **主体类型是硬门槛**：个人主体不能开「社交-笔记」类目。若审核仍按类目判定，彻底解法是**企业主体**（个体户营业执照也可）。
2. **移除用户内容**：去掉记录/语音（保留纪念日、提醒、小游戏），改为纯工具，可继续用个人主体——但会砍掉产品核心。
3. **拆分**：主小程序只保留工具功能（纪念日/提醒/小游戏），用户内容另做企业主体小程序。
