# 首页重塑 · Quiet Editorial

> 2026-11-21 / v1.33.0

## 设计判断

原首页的问题不是“不漂亮”，而是**每个元素都在争抢注意力**：

- 蓝紫渐变背景 + 多色 banner + 白色圆角卡片
- 28 个入口用同一套图标卡片平铺
- 信息密度平均，没有主次；视觉语言更像模板，而不是一个被长期使用的工具

这次采用 **Quiet Editorial（安静的编辑感）** 方向：

- 像一本纸质手册，而不是一个“AI 生成的卡片墙”
- 用**排版、留白、细分隔线、字号层级**建立秩序
- 颜色只保留纸色、墨色、陶土色、鼠尾草绿
- 不用大面积渐变、不用玻璃拟态、不用 emoji 当图标

### 为什么这样分区

- **小火苗 / 菜谱**：低频但重要，放大、留白、给“关系/日常”的情绪入口
- **学习**：高频、目标明确，用列表降低选择成本
- **工具 / 实验室**：多而杂，用双列 tile 统一收纳，避免每张卡片都长得一样重
- **页脚**：用一条线和一行小字收束，不让页面无限下坠

## 细节

- 原生导航改为 `navigationStyle: custom`，用刊头建立品牌；顶部留出状态栏 + 胶囊安全区
- 背景是纸色 + 两层极细点纹（CSS，无图片资源）
- 主卡片圆角 18rpx，tile 14rpx；轻微即可，不做大圆角气泡
- 点击态只做 `opacity + translateY(1rpx)`，不弹跳
- tabBar 图标改为同一套细线图标：home / search / book / user / about
- tabBar 色：未选中 `#9B8671`，选中 `#8C5A3C`，背景 `#F7F1E8`

## 可访问性 / 稳健性

- 所有 28 个入口 handler 与旧首页一一对应，无功能丢失
- 最小点击区域 ≥ 80rpx
- 自定义导航顶部使用 `statusBarHeight + 52px`，避开微信胶囊
- 文本对比度：Ink / Paper ≥ 7:1；辅助文字 ≥ 4.5:1
- 没有引入网络图片、字体包或第三方 UI 库

- 首页入口 handler 对比：old 28 = new 28，无缺失
