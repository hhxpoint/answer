# 小火苗分享封面与文案设计

> 覆盖「我们的小火苗」全部 12 个页面：每个页面都有独立分享封面与对应文案。
> 设计目标：**统一、克制、有编辑感**，和现有暖色 UI 协调，而不是一张通用 logo 图。

---

## 1. 设计系统

| 元素 | 规则 |
|---|---|
| 画布 | 800 × 640（5:4，微信分享卡片安全区） |
| 底色 | 暖白纸感（#FBF6EE → #F3E3D1）+ 低透明暖光 |
| 主色 | 墨棕 #2F261F、铜色 #BC744A、火苗橙 #F09A5A |
| 辅助色 | 玫瑰 #D39389、鼠尾草 #849B80、淡紫 #9187A8 |
| 字体 | 中文：微软雅黑 Light/Bold；英文：Georgia / Georgia Bold |
| 排版 | 左上品牌、右上序号、左侧大标题、下方短文案、底部品牌 |
| 图形 | 抽象火苗（尖顶+圆底）、细轨道环、点线、相纸框、声波、信封、日历环 |
| 质感 | 细网格 + 轻颗粒 + 柔光，避免扁平模板感 |
| 文案 | 每页一句准确、生动、不过度承诺的短句（见下） |

设计关键词：`warm editorial`、`quiet luxury`、`asymmetric`、`thin lines`、`paper grain`。

## 3. 封面生成（可复现）

```text
tools/couple-share/
├─ generate.py       # Pillow 生成 9 张 800×640 分享封面
└─ wire_shares.py    # 给 12 个页面接上封面/文案（一次性脚本，保留可追溯）
packageCouple/
├─ assets/share/*.jpg   # 9 张封面（共约 285KB）
└─ utils/share.js       # 封面映射 + 当前空间路径
```

重新生成：

```bash
python tools/couple-share/generate.py
```

要点：
- 2 倍分辨率渲染后缩放到 800×640，字体/线条更干净
- 火苗用尖顶+圆底的多层形状，避免“橙色鸡蛋”感
- 图形元素统一放在右侧，正文保持安全边距，避免标题与图形碰撞
- 输出 JPEG q86 渐进式，单张约 30–35KB

---

## 4. 页面接入约定

- 每个页面 `require('../../utils/share.js')`
- `onShareAppMessage` 返回 `imageUrl: share.cover('页面名')`
- 空间相关分享路径用 `share.homePath()`；大厅/邀请路径单独处理
- `onShareTimeline` 的 `query` 使用 `share.timelineQuery()`（携带当前 space）
- 新增页面必须同时：加一张专属封面 + 一句准确文案 + 分享路径；否则视为未完成

---

## 5. 包体积与验收

- 9 张封面共约 **285KB**，`packageCouple` 子包约 **0.45MB**（≤2MB）
- 编译：293 个文件 / 产物约 **8.22MB**（≤20MB）
- 验收：
  - [ ] 每个页面右上角分享菜单均可用
  - [ ] 分享卡片显示对应定制封面，不显示旧通用图
  - [ ] 文案与页面一致，无错字/越界
  - [ ] 分享路径能正确进入大厅/当前空间
  - [ ] 图片文字在微信 5:4 裁切下不被切掉
