# 你画我猜 · 双人画板

> 页面：`packageCouple/pages/draw-guess/draw-guess`
> 入口：`packageCouple/pages/home/home` → 侧耳倾听下方「你画我猜」
> 通信：`wss://hhxpoint.me/couple-ws?token=...&space_id=...`

## 1. 设计原则

- **只属于两个人**：没有房间号、没有大厅、没有陌生人；事件只在当前 couple 空间广播。
- **不依赖旧 pictionary 房间服务**：移除 `pictionary` 子包与 `hhxgo.tech` 房间创建。
- **轻量、不落库**：画板内容只走 WebSocket，不写数据库，不保留历史画作。
- **断线可恢复**：WS 自动重连；画手保存当前画布，猜词方重连后通过 `sync_req` / `sync_state` 拉回。

## 2. 对局流程

```text
大厅（双方在线）
  → 开始：发起方为画手
  → 画手选词（服务端不下发；画手本地持有）
  → 画手实时画 → 猜词方实时看
  → 猜词方输入答案 → 画手判定
       ├─ 正确：猜词方 +100，2 秒后进入下一回合
       └─ 超时：公布答案，下一回合
  → 下一回合交换画手
  → 5 回合后结算：分数 / 胜者 / 平局
```

默认 5 回合，可在 3 / 5 / 8 中切换。

## 3. WebSocket 事件

客户端发送：

```json
{ "type": "pictionary", "payload": { "action": "round_start", ... } }
```

服务端 `src/ws.js` 只做：

1. 校验 token、couple 成员身份（沿用 `/couple-ws`）；
2. 把 `pictionary` 事件广播给同一 `coupleId`；
3. 附带 `from`、`ts`、`space_id`。

事件：

| action | 方向 | 说明 |
|---|---|---|
| `round_start` | 画手 → 双方 | 回合、画手、掩码、分类、分数、结束时间 |
| `point` | 画手 → 猜词方 | 两点线段，节流约 45ms，实时笔迹 |
| `stroke` | 画手 → 猜词方 | 一笔完整点集，用于对账/重绘 |
| `clear` / `strokes` | 画手 → 猜词方 | 清空 / 撤销后全量同步 |
| `guess` | 猜词方 → 画手 | 猜词文本 |
| `correct` | 画手 → 猜词方 | 答案、分数 |
| `round_end` | 画手 → 双方 | 答案、原因、下一回合/画手 |
| `game_over` | 画手 → 双方 | 最终分数 |
| `hint` | 画手 → 猜词方 | 一个字提示 |
| `sync_req` / `sync_state` | 重连对账 | 画手回传画布/分数/剩余时间 |
| `leave` | 任意 → 对方 | 对方离开，结束对局 |

## 4. 画板实现

- 使用 `<canvas type="2d">`，按设备 pixelRatio 缩放，避免模糊。
- 坐标归一化到 0~1，双方分辨率/宽度不同也能一致。
- 本地触摸时即时画；远端每 45ms 收线段，落笔结束再发完整笔画。
- 颜色：8 个低饱和治愈色；笔刷：4/7/11；支持橡皮、撤销、清空、提示。
- 撤销只保留最近笔画，避免事件过大；`strokes` 全量同步。

## 5. 体验与文案

- 奶油底色 + 暖橘/鼠尾草绿 + 圆角卡片，贴合小火苗主页。
- 文案避免「社交/陌生人/房间」；使用「TA」「我们俩」「小画板」。
- 分数牌、回合牌、倒计时；最后 10 秒轻微呼吸动画。
- 结算：`你赢了 / TA 赢了 / 平局` + 再画一局 / 回到小火苗。
